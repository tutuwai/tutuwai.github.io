## 7. 项目数据结构（推荐方案）
为了“新增项目不改 UI 代码”，建议用**数据驱动**。
当前版本可先不创建该数据文件，等进入 Phase 2 再补齐。

### 7.1 方案 A：`projects.json`（最简单）
建议字段：
- `slug`（唯一标识）
- `title`
- `description`（one-liner）
- `highlights`（数组）
- `tech`（数组 tags）
- `links`（对象：`github` 必需，`demo`/`writeup` 可选）
- `featured`（boolean）
- `date`（可选）
- `cover`（可选）

示例（仅示意，后续按你实际内容改）：
```json
[
  {
    "slug": "personal-website",
    "title": "Personal Website",
    "description": "A fast, SEO-friendly personal site to showcase my resume and projects.",
    "highlights": [
      "Built with Astro and deployed via GitHub Pages",
      "Projects are managed as data for easy updates"
    ],
    "tech": ["Astro", "TypeScript", "TailwindCSS"],
    "links": {
      "github": "https://github.com/<user>/<repo>",
      "demo": "https://<user>.github.io/<repo>/"
    },
    "featured": true,
    "date": "2026-02",
    "cover": "/projects/personal-website.png"
  }
]
```

### 7.2 方案 B：`content/projects/*.md`（更灵活）
每个项目一个 Markdown 文件，便于写更长说明。Frontmatter 字段建议与 JSON 类似：
```md
---
slug: personal-website
title: Personal Website
description: A fast, SEO-friendly personal site to showcase my resume and projects.
featured: true
date: 2026-02
tech:
  - Astro
  - TypeScript
  - TailwindCSS
links:
  github: https://github.com/<user>/<repo>
  demo: https://<user>.github.io/<repo>/
cover: /projects/personal-website.png
---

## Highlights
- Built with Astro and deployed via GitHub Pages
- Projects are managed as content for easy updates
```
